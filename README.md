A hands-on collection of **network forensics and SOC investigation labs** using **Wireshark**. Each lab analyzes real PCAP files to identify threats, reconstruct communications, and document findings — mirroring the day-to-day work of a SOC Analyst.

---

## 🎯 Project Overview

The goal of this project is to develop practical skills in **network forensics, packet analysis, threat detection, and incident investigation** by analyzing network traffic and identifying suspicious activity in captured PCAP files.

Each lab follows a structured **investigation workflow**:
1. Capture / load the PCAP
2. Apply display filters to isolate relevant traffic
3. Analyze patterns, streams, and credentials
4. Document findings and evidence

---

## 🔬 Labs Covered

| # | Lab | Objective | Key Skills |
|---|-----|-----------|------------|
| 1 | **Identify the Attacker's IP** | Analyze traffic to pinpoint the attacker's IP | Packet filtering, suspicious communication patterns |
| 2 | **Follow TCP Stream — Part 1** | Reconstruct a TCP conversation | Stream reconstruction, client-server analysis |
| 3 | **Follow TCP Stream — Part 2** | Investigate streams in a new capture | Hidden data extraction, traffic analysis |
| 4 | **HTTP Plain Text Credentials** | Find exposed usernames & passwords | HTTP inspection, credential risk assessment |
| 5 | **Catch the Brute Force Attacker** | Detect repeated login attempts | Authentication analysis, brute-force detection |
| 6 | **Catch the Call Scammer** | Investigate a suspicious call capture | Communication pattern analysis, evidence gathering |
